# Security Policy

## Supported Versions

Only the current main version of this repository is supported for security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

As a security-centric project designed to protect Personally Identifiable Information (PII) from data leakages, security is our top priority. If you discover a vulnerability or security flaw, please do not open a public issue.

Instead, please report it privately via email directly to the project architect:

**Andrew Yeo**  
Email: [andrew.yeo.mc@gmail.com](mailto:andrew.yeo.mc@gmail.com)

Please include the following details in your report:
*   Description of the vulnerability and the potential impact.
*   Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
*   Suggestions for remediation (if available).

We will acknowledge your report within 48 hours and work with you to release a security patch before public disclosure.
